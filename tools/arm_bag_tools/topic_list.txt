# arm_bag_tools job 档默认录制话题（ARM_BAG_PROFILE=job）
# Episode 切分：同一 bag 内按 /manipulator/job_event 的 job_id + STARTED/终态时间戳切 PICK 与 TARGET_INSERT。
# 推荐任务链：Target 抓取（robotic_arm_cmd type=0）→ 插孔（type=1）；勿混缆绳 type=2。
# 单位：关节 bag 内 joint_states 为 rad；AgentCommand / ArmSensor 关节为 deg。

## A 任务与状态
/manipulator/job_event                          sealien_ctrlpilot_manipulator_orion_mtc_msgs/JobEvent          ~事件驱动    job 生命周期 SUBMITTED/STARTED/SUCCEEDED/FAILED
/manipulator/task_stage                         sealien_ctrlpilot_manipulator_orion_mtc_msgs/TaskStage         ~阶段切换    MTC 阶段 ENTER/RUNNING/DONE/FAILED
/manipulator/runtime_status                     sealien_ctrlpilot_manipulator_orion_mtc_msgs/RuntimeStatus     ~2 Hz        队列与 task_mode 快照
/manipulator/held_object_state                  sealien_ctrlpilot_manipulator_orion_mtc_msgs/HeldObjectState   ~事件/变化   持物上下文

## 本仓库当前不提供（data_final B 类）
# 关节/末端连续力力矩、仿真接触力、碰撞事件真值 — 无对应话题

## 抓取/插孔离散真值（仿真）
# 抓取：left_arm_gripped >= 0.5（config: gripper_feedback.lock_threshold）
# 插孔：target_set.latches[i] > 0.5（HoloOcean TargetSensor；job 终态可能与 latch 不一致，见 MTC 日志）

## 插孔 world model 对齐（InsertRelativeState + AgentCommand）
# 窗口：TARGET_INSERT 的 move to pre-insert ENTER 起，至 open hand ENTER 前（insert_rel_state.active=true）
# s_t：/manipulator/insert_rel_state（relative_pose 或 lateral/axial/angle_error）
# a_t：/holoocean/command/agent/arm（~50 Hz，关节 deg）
# s_{t+1}：下一帧 insert_rel_state；离线用 extract_insert_trajectories.sh 自动对齐 AgentCommand
