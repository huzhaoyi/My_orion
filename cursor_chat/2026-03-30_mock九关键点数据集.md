# Mock 九关键点（声纳缆线样例）

## 进展

- 将用户提供的 9 组 `(x,y,z)` 固化为 `keypoint_to_arm_tf_node` 内 `MOCK_KP_SONAR_CABLE_9`，通过参数 **`mock_preset:=sonar_cable_9`** 在 `use_mock_keypoints=true` 时注入。
- 默认 **`mock_preset:=legacy_single`** 仍为原单点 `mock_kp_*` 行为；未知 preset 打 ERROR 并回退 legacy_single。
- `keypoint_arm_tf.launch.py` 增加启动参数 **`mock_preset`**（默认 `legacy_single`）。

## 使用示例

```bash
ros2 launch orion_mtc keypoint_arm_tf.launch.py use_mock_keypoints:=true mock_preset:=sonar_cable_9
```

## 完成情况

- `colcon build --packages-select orion_mtc` 通过。
