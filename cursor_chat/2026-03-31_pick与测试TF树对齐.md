# pick_holoocean 与 keypoint 独立测试 TF 树对齐

## 目标

独立 `keypoint_arm_tf.launch.py` 使用 `camera→sensor_link→left_arm_base/right_arm_base` 拟合；pick 此前在 `base_link`（≈camera）拟合，与测试不一致。

## 修改（`keypoint_arm_tf.launch.py`）

- **`tf_under` 分支**：除 `base_link→camera`、`camera→sensor_link` 外，**增加与同文件独立分支相同的** `sensor_link→left_arm_base`、`sensor_link→right_arm_base` 静态 TF。
- **节点参数**：`left_arm_frame` / `right_arm_frame` 改为 **`left_arm_base`** / **`right_arm_base`**；**`output_grasp_frame`：`base_link`**，`tryPublishFusedGrasp` 将位姿从拟合系变到 MTC 规划系。

## 行为

- 与独立测试相同的感知链上做点云/中心线；融合抓取话题仍在 **`base_link`**。
