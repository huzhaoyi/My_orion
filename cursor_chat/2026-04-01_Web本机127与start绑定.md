# Web 默认本机：WS 127.0.0.1 与 start.sh

## 改动

- **`web/js/data/wsClient.js`**：`getDefaultWsUrl()` 固定 `ws://127.0.0.1:9090`，不再使用 `window.location.hostname`（避免用局域网 IP 打开页面时 rosbridge 也走局域网）。
- **`web/start.sh`**：默认 **`--bind 127.0.0.1`**；需局域网访问时：`./start.sh 8080 0.0.0.0`。
- **`TopBar.js` / `main.js` / README**：文案与说明对齐。

## 覆盖

远程 rosbridge：`?ws=ws://实际主机:9090`。
