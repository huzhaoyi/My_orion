# 阶段中文与彩色胶囊

## 需求

「当前执行」与事件流中阶段名统一中文，并用颜色区分阶段类型。

## 实现

- **`web/js/data/labels.js`**：补全侧抓 MTC 阶段、开闭爪等 `stage_name` → 中文；`stageNameLabel` 支持空格键与下划线键fallback；新增 `stagePillClass` / `stageStateModifier`（运行中高亮描边、失败红框）。
- **`theme.css`**：`.stage-pill` 及 `--meta/--ready/--open/--close/--approach/--retreat/--scene/--cable/--task/--default/--idle`。
- **`RuntimeStatusCard.js`**：阶段行使用 `<span class="stage-pill …">`。
- **`BottomLogPanel.js`**：含 `stage_name` 的事件行包裹同色胶囊。
