# 融合姿态「正负」跳变：原因与代码修复

## 原因

1. **PCA 主轴** `principalDirectionMax` 使用 `SelfAdjointEigenSolver` 的特征向量，**±v 等价**，帧间符号随机 → 沿缆排序反向 → 局部切向/`seg_hint` 抖动。
2. **`sideGraspQuaternionFromAxis`** 原先用 **`a.z() < 0` 就把切向取反**，在切向接近水平、\(z\) 含噪声时会在零附近来回翻转，等效 **180°** 姿态跳变。
3. **四元数双覆盖**：**q** 与 **−q** 同一旋转，若不固定半空间，UI/手写监控会看到 **qx/qw 等符号来回变**（欧拉角更明显不连续）。

## 修改（`keypoint_to_arm_tf_node.cpp`）

1. **`principalDirectionMax`**：在最大绝对值分量上固定符号（该分量恒正）。
2. **`sideGraspQuaternionFromAxis`**：增加 **`cable_axis_ref`**（与 `runCenterlineGraspTest` 中 `axis_global` 同向）；用 **`a·ref ≥ 0`** 对齐切向，**删除** 纯 `z>0` 判据。
3. **`sideGraspQuaternionFromAxis`** 与 **`applyFusedOrientationCorrection`**：**`w < 0` 时对四元数系数整体取反**，与 ROS 常见约定一致，减轻显示层「正负跳」。

## 假设

- 单段缆线 PCA 主轴与真实走向一致；极端退化（多点共线噪声）仍可能偶发跳变，可再加大中值窗口或 temporal 滤波。
