# 融合姿态：侧抓结果左乘标定四元数（非直连 /object_pose）

## 需求

中心线/side-grasp 算出的 `object_pose_fused` 姿态与 `/object_pose`（桥接）约定不一致；需对**计算出的**四元数做旋转标定，使**结果**与桥接一致，**不**直接订阅或复制桥接话题。

## 实现

- `keypoint_to_arm_tf_node`：参数 `fused_grasp_orientation_correction_w/x/y/z`（Eigen 序 w,x,y,z），对侧抓 `q_side` **左乘**：`q_out = q_corr * q_side`，再参与 TF 与发布。
- 标定公式（同帧、同系，如 base_link）：`q_corr = q_bridge * inverse(q_side)`。
- `keypoint_arm_tf.launch.py` 在 `tf_under_manipulator` 且非 platform 分支写入一组**示例**标定（来自用户一帧数据）；环境变化需重算或设 `w=1,x=y=z=0`。
- README 已补充参数与标定说明。
