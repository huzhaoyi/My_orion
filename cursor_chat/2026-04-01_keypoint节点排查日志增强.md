# keypoint_to_arm_tf：转换失败 / 未发布 日志

## 新增/强化 WARN_THROTTLE（约 2～5 s）

- **grasp_position**：`centerline_arclength` / `mean` / `keypoint_index` 在指定索引上 TF `source`→`left_arm_frame` 失败时，说明 **object_pose_fused 未参与发布** 原因。
- **centerline_arclength_grasp_position** 返回 false 时单独一条。
- **directions**：向量 TF 失败；**euler**：`lookupRotation` 失败。
- **tryPublishFusedGrasp**：末级 TF `left_arm_frame`→`output_grasp_frame` 失败时打出 **话题名** `grasp_pose_topic` / `grasp_axis_topic`。
- **keypoints_posearray**：全部点 TF 失败导致 **未发布 PoseArray** 时打出点数、`source`→`output_grasp_frame`、**keypoints_posearray_topic**；部分失败仍为原有统计行。
- **publish_fused_grasp_topics=false**：DEBUG_THROTTLE 说明仍可能发 keypoints_posearray。
