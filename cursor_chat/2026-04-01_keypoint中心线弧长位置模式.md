# keypoint_to_arm_tf：`centerline_arclength` 位置模式

## 实现

- **`fused_grasp_position_mode`**: 新增 **`centerline_arclength`**（默认仍为 **`mean`**）。
- 流程（均在 **`left_arm_frame`**）：关键点 TF 到臂系 → 协方差 **全局 PCA** 主轴投影排序 → 可选 **`centerline_dedupe_radius_m`**（默认 **0** 不去重）→ **`centerline_median_window`**（默认 **1** 不平滑；**>1** 时为沿折线对**真实顶点**的 **3D 算术均值**，非分量中值）→ **`centerline_grasp_arclength_fraction`**（默认 **0.5**）弧长插值。
- **未恢复** 局部 PCA 切向；**`object_pose` 姿态与 `object_axis_fused`** 仍只用消息 **`directions` / `euler_angles`**（原 `publishFusedFromMsgAttitude` 逻辑）。

## 用法示例

```bash
ros2 run orion_mtc keypoint_to_arm_tf_node --ros-args \
  -p fused_grasp_position_mode:=centerline_arclength \
  -p centerline_dedupe_radius_m:=0.0 \
  -p centerline_median_window:=1 \
  -p centerline_grasp_arclength_fraction:=0.5
```
