# 抓取回预抓取位后闭合夹爪

## 需求

缆绳侧抓任务结束时，在回到预抓取位之后需要再次闭合夹爪（硬件/流程上保证最终位姿下手爪为闭合）。

## 实现

1. **`pick_task_builder.cpp`**  
   在原有「闭爪 → 删缆段 → 短退」之后增加：
   - `move to pregrasp (holding)`：PTP 回到与接近前相同的预抓取位姿（持绳 assumed closed）
   - `close hand (at pregrasp)`：在预抓取位再执行一次 hand 组 `close`

2. **`solution_executor.cpp`**  
   「张开后等待解锁」仅在轨迹末端姿态**明显张开**（与 SRDF open 量级一致，`|q| > 0.25`）时触发，避免第二次闭合段被误判为 `wait_for_gripped(false)` 导致逻辑错误。

3. **`task_manager.cpp`**  
   `PICK_STAGE_NAMES_CABLE_SIDE` 追加上述两阶段名，便于上报/前端对齐。

4. **`pick_task_builder.hpp`**  
   注释与行为一致。
