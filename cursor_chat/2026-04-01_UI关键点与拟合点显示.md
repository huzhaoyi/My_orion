# Web：Keypoints 坐标 + 3D 琥珀点 / 品红拟合点

## ROS

- `keypoint_to_arm_tf_node` 新增 **`geometry_msgs/PoseArray`**，默认话题 **`/manipulator/keypoints_base_link`**（`keypoints_posearray_topic` / `publish_keypoints_posearray`）。
- 每个 `pose.position` 为单个关键点已 TF 到 **`output_grasp_frame`**，并叠 **`fused_grasp_position_z_offset_m`**，与 `object_pose_fused` 一致。

## Web

- **wsClient**：订阅 `prefix + '/keypoints_base_link'`，`setKeypointsTrace`。
- **stateStore**：`keypointsTrace` / `keypointsTraceValid` / `keypointsTraceUpdatedAt`。
- **PerceptionCard**：关键点点列 `#0..` 与图例（青桥接 / 品红拟合 / 琥珀关键点）。
- **RobotScene / Viewport3D**：最多 32 个琥珀球 + 折线；与「目标点」图层联动。**品红** = `pickMarkerFused`（拟合抓取点）。

## 依赖

须运行 **keypoint_to_arm_tf** 且 TF 可达；断连 ws 时清空 keypoints 缓存。
